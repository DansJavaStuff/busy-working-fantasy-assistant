# Busy Working Fantasy Assistant

A small, non-commercial personal project for analysing data from my Yahoo Fantasy Football league.

The application is intended to use read-only access to the Yahoo Fantasy Sports API to retrieve information such as:

- League settings
- Teams and rosters
- Available players
- Draft results
- Standings
- Player information

## Planned features

### Draft Assistant

During a fantasy draft, the application will maintain an up-to-date view of drafted and available players and help evaluate potential selections.

### Weekly Fantasy Dashboard

During the NFL season, the application will provide a dashboard for:

- Reviewing my current roster
- Identifying available players
- Waiver-wire analysis
- Start/sit decisions
- League and matchup information

## API Access

The project is currently intended to use read-only Yahoo Fantasy Sports API access.

It does not submit waiver claims, add/drop players, change lineups or perform other write operations.

## Status

Early development / API integration testing.
